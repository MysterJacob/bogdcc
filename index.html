8 Bit Computer

https://github.com/MysterJacob/8-bit-assembler https://www.youtube.com/watch?v=WDrS0C0M3HM

My adaptation of Ben Eater's 8Bit breadboard computer.

It was heav modified. Program is read from rom of capacity of 8KiB instead of 64 byte long RAM. Each instruction might have a parameter, so there is no need to allocate RAM memory. You can do LVA 0xFF (register A, load value 0xFF) instead of loading it manually into RAM and reading it from there.

I've made a custom compiler, so writing programs is much easier.

There is also buzzer, user input buttons etc.
