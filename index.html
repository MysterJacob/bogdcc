8 Bit Computer

https://github.com/MysterJacob/8-bit-assembler https://www.youtube.com/watch?v=WDrS0C0M3HM

My adaptation of Ben Eater's 8Bit breadboard computer.

I created a heavily modified adaptation of the Ben Eater 8‑bit breadboard computer. The major enhancements include: 8 KiB ROM program memory instead of a 64‑byte RAM program area Instruction parameters, eliminating the need to store immediate values in RAM e.g., LVA 0xFF directly loads 0xFF into register A A custom compiler to simplify writing and assembling programs Additional components such as a buzzer, user‑input buttons, and other interface elements

Home Core

Source code is not currently public.

Home Core manages automation, cameras and security alerts. It's not a single device, more like network of connected nodes with central server on Raspberry PI. When sensor detect access to protected area without authorization central server can send a warning to admin's mobile phone. If camera are installed in location, photo or video of intruder can also be send.

With multiple access points system can be controlled from any point.

All of Home Core systems are modular and can be managed independent
